Changelog

1.4.0 · 2026-10-08

  • Inline notification (new page): .sys-note for context (yellow rule on pale yellow) and .sys-note--alert for things that need action: the same container, led by a status tag (Critical is the black box with yellow type).
  • New token --highlight-soft: #fffbe0, the pale yellow behind a note.
  • Docs icons: the J© bug from jonesco.com on magenta, as the favicon, Apple touch icon and Android icons.
  • Missing data is yellow (Data & charts): a month not recorded is a --highlight bar instead of the gray track.

1.3.1 · 2026-10-08

  • Newsprint can block in a section: besides sitting behind artwork, it can fill or contain a section. Still never the whole page.
  • Docs: the sidebar keeps its scroll position from page to page.
  • Ghost buttons are outline only: .sys-btn--ghost has no fill, a black border, and fills black on hover. Newsprint is for artwork, not buttons.

1.3.0 · 2026-10-08

  • Newsprint replaces cream. --newsprint: #edebe6, a warm light gray that reads as paper against white (17.6:1 with black type) and sits a step darker than the --gray track. It’s the “paper” behind artwork and the ghost button.
  • --cream stays as a deprecated alias that now points at --newsprint; sites should switch to the new name.
  • .sys-paper and .sys-btn--ghost use newsprint. Principles and docs say newsprint throughout.

1.2.1 · 2026-10-08

  • Financial Dashboard demo: a public demo of the dashboard with a made-up household, linked from its site page. Built from the real dashboard’s code, so its structure stays in step.
  • The site is now called Financial Dashboard throughout the docs.
  • Docs only, plus a comment in patterns.css; no visual change.

1.2.0 · 2026-10-08

  • Data color (Data & charts): --data, --data-300, --data-200, --data-100 in system.css. Cyan by default; the main step is the darkest. Rules for one hue, missing data, hover, targets and the accent.
  • patterns.css, from the Financial Dashboard: block title, stat and .sys-mark, meter and split bar, switch (toggle and tabs), label and icon buttons, section nav with .sys-section, and tag status levels (.sys-tag--outline, .sys-tag--plain).
  • Additions only: nothing existing changes, so sites pinned to 1.1.x look the same.
  • New site page: Financial Dashboard.

1.1.1 · 2026-10-06

  • Sites: two sites now, jonescoartdept.com and jonesco.com. The portfolio site became jonesco.com, so its variations moved to the jonesco.com page.
  • Docs only; system.css and patterns.css are unchanged.

1.1.0 · 2026-10-04

  • Case rule (Typography · Case): caps for the one hero per page, sentence case for titles you read in groups, caps for short labels.
  • patterns.css: new .sys-title helper; .sys-tile__title is now sentence case in Bold No. 2.
