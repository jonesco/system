Stipulations

  • Everything is left-aligned: headers, text and numbers. Tabular digits keep amounts readable without right-aligning them (Data & charts).
  • The panel carries the padding. Put the table in a .sys-table panel; don’t put a border around it or give it rounded corners. Rules run the full width inside the padding.
  • Newsprint is the table’s own block, so the table can sit on white or on black. Its type stays ink on either.
  • Status goes in a tag (Critical, Warning, Working), at the smaller table size; the Working tag turns white so it shows on the newsprint. Rows that need nothing say so in plain text. Values stay ink and never take the data color.
  • Write amounts the same way down a column: the same decimals and the same currency sign on every row.
  • No zebra stripes and no row hover. A link in a cell turns magenta on hover, as links do elsewhere.
  • When a table is wider than its container, it scrolls sideways inside the panel; the page never does.
