Using the system

Load the foundation, optionally the patterns, then the site’s own stylesheet, which overrides what it needs.

Link it

Pin an exact version so a change to the system never changes a site until you choose to update it.

<link href="https://fonts.googleapis.com/css2?family=Libre+Franklin:wght@400;600;700&display=swap" rel="stylesheet">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/jonesco/system@1.2.0/system.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/jonesco/system@1.2.0/patterns.css">  <!-- optional -->
<link rel="stylesheet" href="/css/site.css">   <!-- the site’s own, last -->

Override a token

In the site’s stylesheet, set only what differs, with a comment saying why.

:root {
  --accent: #1f6feb;   /* jonesco.com uses blue for its accent */
  --size-body: 16px;
}

Versions

  • Patch (1.0.x): fixes that don’t change how anything looks.
  • Minor (1.x.0): new tokens or components; existing ones unchanged.
  • Major (x.0.0): something existing looks or behaves differently.
The Trade Gothic files are the desktop versions. If Trade Gothic becomes permanent across sites, get the web license and swap the files in fonts/; nothing else changes.
