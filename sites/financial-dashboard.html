Financial Dashboard

A household finance dashboard. React + Tailwind, loading the system first. The first data-heavy Jonesco page; the 1.2.0 dashboard patterns come from it.

Open the demo +

The real dashboard is private. The demo is built from the same code with a made-up household, so every name, account and figure in it is fictional. It is rebuilt whenever the real dashboard’s layout changes. Chart colors can be compared by link: blue, green, purple.
